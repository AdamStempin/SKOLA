STUDY HUB SPRINT

[ ] API na správu predmetov – pridávanie, úprava, mazanie a zobrazovanie predmetov.

[ ] API na správu úloh – termíny, priority, stav úloh a filtrovanie.

[ ] Automatické vyhodnocovanie termínov – kontrola oneskorených a blížiacich sa úloh.

[ ] Štatistiky učenia – výpočet času učenia, úspešnosti a dokončených úloh.

[ ] Pomodoro API – zaznamenávanie a vyhodnocovanie študijných relácií.

[ ] Inteligentné plánovanie – rozdelenie učiva podľa náročnosti a termínu skúšky.

[ ] Vyhľadávanie – vyhľadávanie úloh, predmetov a poznámok podľa názvu alebo obsahu.

[ ] Validácia údajov – kontrola správnosti dát pred uložením.

[ ] REST API – vytvorenie endpointov na komunikáciu s Angularom.

[ ] Autorizácia požiadaviek – overovanie Firebase tokenov a prístup používateľa k jeho údajom.

[ ] Export údajov – generovanie prehľadu úloh alebo štatistík do PDF/CSV.

[ ] Generovanie študijného plánu – vytvorenie plánu na základe skúšok, úloh a dostupného času.
